# Description

Auto-Type: a global hotkey types an entry's username/password sequence into the frontmost window of another app, like KeePassXC and MacPass.

Goals:
- Use the KeePass Auto-Type data that KeePassKit already reads and writes (`KPKEntry.autotype`: enabled, default sequence, window associations; `KPKGroup.isAutoTypeEnabled` with inheritance, `defaultAutoTypeSequence`), so settings stay compatible with KeePass, KeePassXC and MacPass.
- Type into any app with the default sequence `{USERNAME}{TAB}{PASSWORD}{ENTER}`.

Stack: Swift 6.1, SwiftUI/AppKit, KeePassKit (`KPKAutotype`, `KPKWindowAssociation.matchesWindowTitle`, `kpk_normalizedAutotypeSequence`, `kpk_finalValue`), Accessibility API (`AXUIElement`, `AXIsProcessTrustedWithOptions`), Quartz events (`CGEvent`), Carbon hotkey (same mechanism as Quick Access). No new libraries.

Design: mockups in the existing Claude Design project `KeeMac.dc.html` (Step 0), built from existing components (`.kmField`, `KMSegmentedControl`, `.kmCard`, `KMButtonStyle`, Quick Access panel). The only new component is the window association list in the editor.

## Decisions

- **Matching** (`C`): explicit window associations (KeePass `*` wildcards) + entry title contained in the window title. For browsers whose address bar is readable through Accessibility (Safari, Chromium-based: Chrome, Arc, Edge, Brave, Vivaldi, Opera) the tab URL is also matched against entry URLs with the existing `BrowserMatching`. No AppleScript / Automation permission; Firefox and others fall back to title matching.
- **Picker** (`A`): the Quick Access panel gets an Auto-Type mode: header "Type into: <app — window>", matched entries first, search over the whole database, Enter types, Esc cancels. One match types immediately without the panel; no match opens the panel with an empty search. Unlocking and re-locking work like Quick Access (`LockReason.quickAccess`).
- **Hotkey** (`A`): separate global Auto-Type hotkey, default ⌃⌥⌘A, configurable in Settings. Quick Access is unchanged.
- **Editing** (`A`): full editing. Entry: enable, inherited or custom sequence, list of window associations (title pattern + optional own sequence) with add/remove. Group: Auto-Type enabled (inherit / yes / no) and default sequence.
- **Entry points** (`A`): the global hotkey only. No "Perform Auto-Type" button in the entry card, no "Type" action in regular Quick Access.
- **Typing** (`A`): text goes as Unicode events (`CGEventKeyboardSetUnicodeString`), special keys and shortcuts as virtual key codes. Independent of the keyboard layout. RDP/VNC/VM/games that read key codes are out of scope.
- Main database only (like Quick Access and browser integration); additional databases are not searched.
- Accessibility permission is required for both reading window titles and typing. Settings show its status with an "Open System Settings" button; the hotkey without permission shows the request instead of typing.
- Secure Input (`IsSecureEventInputEnabled`) blocks typing: detect it and show a notice instead of typing into nothing.
- Before typing: hide the panel, reactivate the target app, wait until the hotkey modifiers are released, then type with a short delay between events (default 10 ms, `{DELAY=…}` overrides).
- `{TOTP}` / `{HMACOTP}` are resolved when typing; HOTP advances the counter (same rule as browser and Quick Access).
- UI testing mode: no global hotkey, typing goes to a test sink instead of `CGEvent`.

Permission status refreshes when the user returns from System Settings.
- **Notices** ("Auto-Type notice", floating panel under the menu bar icon like Quick Access): "Accessibility access needed" (Not Now / Open System Settings…); "Secure input is on in <App>" — "KeeMac can’t type there. - Match ranking: explicit association first, then URL, then title (the mockup lists Title before URL; KeeMac ranks URL higher because it is the stronger signal).

## Sequence syntax (KeePass)

Plain text; `{USERNAME}`, `{PASSWORD}`, `{TITLE}`, `{URL}`, `{NOTES}`, `{S:Field}`, `{REF:…}` and other placeholders via `kpk_finalValue`; `{TOTP}`, `{HMACOTP}`; keys `{TAB}`, `{ENTER}`, `{SPACE}`, `{BACKSPACE}`/`{BS}`, `{DELETE}`/`{DEL}`, `{ESC}`, `{UP}`/`{DOWN}`/`{LEFT}`/`{RIGHT}`, `{HOME}`, `{END}`, `{PGUP}`, `{PGDN}`, `{INSERT}`, `{F1}`…`{F16}`; repeats `{TAB 3}`; modifiers `+` (Shift), `^` (Control, mapped to ⌘ for shortcuts like `^a`), `%` (Option), `@` (Command) applied to the next key or `(group)`; literal `{+}`, `{^}`, `{%}`, `{@}`, `{~}`, `{{}`, `{}}`, `~` = Enter; `{DELAY 500}`, `{DELAY=50}`; `{CLEARFIELD}` (select all + delete). Unknown commands are an error shown to the user, nothing is typed.

# Implementation

## Step 0: Design
[x] Claude Design mockups in `KeeMac.dc.html`: entry editor Auto-Type section with window associations, group editor Auto-Type, Quick Access Auto-Type mode, Settings section, Accessibility / Secure Input notices

## Step 1: Domain model and loader
[x] `VaultAutoTypeSettings` (enabled, custom sequence, associations) on `VaultEntry` and `VaultEntryForm`; group settings (enabled inherit/yes/no, default sequence) on `VaultGroup` and the group form
[x] Loader reads/writes `KPKEntry.autotype` and group Auto-Type fields; every form built from an entry carries the settings (like `sshAgent`)
[x] Effective sequence: association → entry → group chain → database default; effective enabled with group inheritance

## Step 2: Sequence parser
[x] Parse a sequence into actions: text, key (with modifiers and repeat), delay, default-delay change, clear field
[x] Placeholder resolution in the loader: `kpk_finalValue` for fields and references, `{TOTP}` / `{HMACOTP}` with HOTP advance; resolved secrets live only in the action list
[x] Validation for the editor (unknown command, unbalanced braces)

## Step 3: Window context and matching
[x] `AutoTypeWindowContext`: app name, bundle ID, PID, window title (AX `kAXFocusedWindow` / `kAXTitle`), tab URL for Safari and Chromium browsers (AX address field / `AXDocument` / web area URL)
[x] Matcher: enabled entries outside the recycle bin; associations via `matchesWindowTitle`, entry title in window title, URL via `BrowserMatching`; ranked (association > URL > title), the association's sequence wins

## Step 4: Typing
[ ] `AccessibilityPermission`: status, prompt, open System Settings
[ ] `KeystrokeTyper`: Unicode text events, virtual key codes and modifiers, delays; wait for released modifiers; Secure Input check; cancel on Esc
[ ] Test sink for UI testing mode

## Step 5: Hotkey and picker

[ ] Flow: capture context → unlock if needed → match → type directly / Quick Access in Auto-Type mode → reactivate target → type → re-lock if Quick Access unlocked
[ ] Quick Access Auto-Type mode: header with target, matched entries first, search, Enter types, Esc cancels
